system architecture, end to end

How it's wired.

One bug in, one verified fix out. Each box is a stage. The text between them is what happens at the handoff.
Bug Input
QA file or GitHub Issue
The system picks up the bug and opens a clean run folder.
Briefing
Bash scan · no AI yet
It reads the codebase like an engineer scanning for clues: affected files, recent commits, error strings, the test command.
Diagnose
Agent · senior QA
Two theories compete. Evidence picks the winner. Only the verdict moves forward, never the scratch work.
Fix
Agent · senior engineer
One focused change is written from the verdict. If the evidence is thin, the agent refuses and explains why.
Verify
Agent · isolated workspace
The fix is applied in isolation, every test runs, and a brand-new test is written for the original bug. The developer's working tree is never touched.
Developer
Reads · approves · ships
Across every stage: no commits, no network calls, no edits outside the run folder. Every step is logged and reviewable.
